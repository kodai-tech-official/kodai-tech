## ⚡ Active Environment Modules

The workspace features a collection of high-performance developer tools designed to execute entirely within your browser runtime (zero external dependencies, zero data logging):

1. **`01 / KEY_GENERATOR`** (Cryptographic Key Generator)
   * High-entropy strings generation using secure crypto APIs.
   * Granular controls: Uppercase, Lowercase, Numbers, Symbols, and Ambiguous character filtering (`0, O, l, I`).
2. **`02 / JWT_INSPECTOR`** (JSON Web Token Local Decoder)
   * Instantaneous, local parsing of JWT structure.
   * Separates and formats Header and Payload segments securely in real-time.
3. **`03 / REGEX_WORKBENCH`** (Expression Matcher & Indexer)
   * Evaluates regular expression patterns against custom string payloads.
   * Dynamic support for flags (`g`, `i`, `m`) with detailed match indexing and summary output.
4. **`04 / CSS_CLAMP_CALC`** (Fluid Typography Calculator)
   * Generates clean, production-ready `clamp()` CSS properties for responsive UI design.
